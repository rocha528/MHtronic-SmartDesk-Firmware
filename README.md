# MHtronic SmartDesk - Firmware

Distribuicao publica de firmware assinado digitalmente. O codigo-fonte permanece privado.

Instale atualizacoes pelo menu Wi-Fi > Sistema / Firmware do aparelho e confirme no display.

A chave publica neste repositorio permite verificar assinaturas. A chave privada nao e publicada. O binario pode ser baixado e analisado por terceiros.
